## 3. Common failure patterns to hunt

1. *Estimand conflation* — semantic-equivalence language leaking into resource-equivalence claims (Doc 08 §5.4).
2. *Package attribution* — a bundle-level benefit silently attributed to one primitive (§6.1 last para).
3. *Control asymmetry* — any target-only mandatory state in the shared interface (§18.1).
4. *Threshold drift* — numbers stated as binding before DQ2 signature (Doc 07 §6).
